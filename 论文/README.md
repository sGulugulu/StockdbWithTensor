# 论文版本快照索引

本目录用于保存论文正文与模板的阶段性快照，方便对比、回退与后续迭代。

## 当前约定

- 目录命名统一使用 `vN 版本标题`
- 每个版本目录至少包含：
  - `template.tex`
  - `paper_body.tex`
  - `template.pdf`
  - `template.log`
  - 其它由 XeLaTeX 生成的中间产物
- 后续新版本继续按以下模式新增：
  - `v3 xxxx`
  - `v4 xxxx`
  - `v5 xxxx`

## 使用建议

- 需要回退时，优先从对应版本目录取 `template.tex` 与 `paper_body.tex`
- 需要比较展示效果时，直接对比各版本目录中的 `template.pdf`
- 每次形成新的可提交阶段，先新建版本目录，再复制源码与编译产物，避免覆盖旧版本
